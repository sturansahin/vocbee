# 10 — i18n / Localization Yapısı

## Mevcut Durum

- **`services/i18n.ts`:** i18next + react-i18next init (i18next ^25.8.0, react-i18next ^16.5.4).
  Test edilmiş: `services/__tests__/i18n.test.ts`.
- **`locales/index.ts`:** dil kaynaklarını toplayıp i18next'e verir.
- AsyncStorage `@user_language` ile UI dili; `@native_language` / `@target_language` öğrenme dilleri
  (i18n UI dilinden ayrı; bkz. `08`).
- `utils/rtl.ts` (RTL dil desteği) mevcut.

## Sorunlar

1. i18n init `services/` altında; tasarım olarak cross-cutting `shared` alanına ait.
2. UI dili (`@user_language`) ile öğrenme dili (`@native/target_language`) kavram karışıklığı riski.
3. Çeviri anahtarlarının eksik/fazla olduğunu yakalayan otomatik kontrol yok.

## Önerilen Yaklaşım

i18n'i `shared/i18n` altında toparla; UI-dili ile öğrenme-dilini kavramsal olarak ayır. Yeni paket yok.

```
shared/i18n/
  i18n.ts                 # services/i18n.ts taşınır (init aynı)
  locales/                # locales/* taşınır
  useAppLanguage.ts       # @user_language okuma/yazma + i18n.changeLanguage (UI dili)
  rtl.ts                  # utils/rtl.ts taşınır
```

Öğrenme dilleri (`@native_language`/`@target_language`) i18n'e ait değil → `shared/settings/useLanguagePreferences`
(bkz. `08`) altında kalır. Böylece "UI dili" ile "öğrenilen dil" net ayrışır.

**Opsiyonel kalite kapısı:** eksik çeviri anahtarlarını yakalayan basit bir test (key paritesi) eklenir
(mevcut jest ile; yeni paket gerekmez).

## Alternatifler ve Neden Elendiler

- **i18n kütüphanesini değiştir (lingui vb.)** — Elendi: i18next çalışıyor ve test edilmiş; değiştirmek büyük risk.
- **Çevirileri uzaktan (OTA) yükle** — Elendi (kapsam dışı): offline davranış ve basitlik bozulur.
- **i18n'i `services/`'te bırak** — Elendi: cross-cutting; `shared` daha tutarlı (diğer feature'lar tüketir).

## Migration / Implementasyon Adımları

1. **PR-1:** `services/i18n.ts -> shared/i18n/i18n.ts`, `locales/* -> shared/i18n/locales/*`,
   `utils/rtl.ts -> shared/i18n/rtl.ts`; eski yollardan re-export shim. Init ve davranış aynı.
   - Komut: `npm run typecheck && npm run test:ci`
2. **PR-2:** `useAppLanguage` hook'u çıkar (`@user_language` + `changeLanguage`); UI bileşenleri tüketir.
3. **PR-3 (opsiyonel):** Çeviri anahtar paritesi testi ekle.

Her PR sonunda: `npm run typecheck && npm run test:ci`.

## Riskler

- **`@user_language` anahtarı değişirse** kullanıcı dili sıfırlanır. Azaltım: anahtar `storageKeys`'ten gelir; değer aynı.
- **i18n init sırası:** uygulama açılışında i18n hazır olmadan render edilirse boş metin. Azaltım: mevcut
  init noktası/zamanlaması korunur (App bootstrap; bkz. `03`).
- **RTL davranışı** taşıma sonrası bozulmamalı (`I18nManager`). Azaltım: `rtl.ts` birebir taşınır.

## Test ve Kabul Kriterleri

- Mevcut `services/__tests__/i18n.test.ts` (yeni yolla) yeşil.
- (Opsiyonel) anahtar paritesi testi yeşil.
- `npm run typecheck`, `npm run test:ci` yeşil.
